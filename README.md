# Chrome Forge

把平面黑色图案(如哥特/部落纹样)转成 3D 铬金属模型。纯前端,图片不离开浏览器,three.js 已内置在 `vendor/`,可离线使用。

## 运行

ES module 在 `file://` 下会被浏览器拦截,需要起一个静态服务器:

```bash
cd chrome-forge
python3 -m http.server 8000   # 然后打开 http://localhost:8000
```

## 原理

1. 灰度化 → 模糊 → 阈值,得到形状掩码(黑色图案 = 形状;图案是亮色时勾选"反相")。
2. 对掩码做欧氏距离变换,得到每个像素到边缘的距离。
3. 距离经 Laplacian 平滑(消除中轴线折痕),再套圆形截面 `sqrt(1-(1-t)²)`,得到"充气"高度。
4. 正反面镜像成封闭网格,边缘顶点正反共用,法线连续;轮廓用 Taubin 平滑去除像素阶梯。
5. `MeshStandardMaterial`(metalness 1, roughness 约 0.03)+ 程序生成的高对比环境贴图,产生铬的反射。

## 参数提示

- 阈值:决定哪些像素算"图案"。左上角预览图实时显示提取结果,先把它调干净。
- 充气半径:越大越"胖",细刺不受影响(高度随宽度自然缩小)。
- 液态平滑:越大越像融化的液态金属,太大会丢失细节。
- 反相:默认把图中**深色**部分做成立体。图案是浅色、背景是深色时勾选,等于图案与背景互换。
- 反射环境:铬(高对比)最接近参考图;换环境不会改变模型,只改变反射。

## 背景图

- "上传背景图":图片铺满画面(cover),旋转模型时背景不动;"清除"恢复纯色背景。
- "让铬金属反射背景图":上传背景图后默认勾选。背景图被当作全景图做反射,所以铬面会映出它的颜色和明暗。普通照片的反射会有拉伸,2:1 全景图最自然。
- 没有背景图时,使用上面选择的内置反射环境。

## 导出

- PNG:当前视角。带背景图时会把背景合成进去;勾选"导出 PNG 时不含背景"则只导出模型(透明底)。
- GLB:Blender / Three.js / Unity 可用。
- STL:3D 打印。
- GLB 和 STL 只包含网格,不包含背景图,材质也需要在目标软件里重新设置。

## 部署

纯静态站,无需构建。

- **Cloudflare**(Workers 流程):仓库根目录已有 `wrangler.jsonc` 和 `.assetsignore`。Build command 填 `exit 0`,Deploy command 用默认的 `npx wrangler deploy`。
- **GitHub Pages**:Settings → Pages → Deploy from a branch → `main` / `/ (root)`。

## 已知限制

- 只处理二值轮廓。灰阶渐变的内容(如人物明暗)会被阈值切成色块,不会重建体积。
- 高度由"到边缘的距离"推出,没有真正的深度估计。图案内部的细线条不会单独凸起。
